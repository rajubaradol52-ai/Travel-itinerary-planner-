# Travel Itinerary Planner

## Overview
Travel Itinerary Planner is a simple project that helps users organize and plan their trips efficiently.

## Features
- Create a travel itinerary
- Add destinations
- Plan activities
- Organize travel dates
- Keep trip information in one place

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Goal
The goal of this project is to provide an easy and efficient way to plan trips.

## Future Enhancements
- Weather information
- Map integration
- Hotel and flight details
- Budget tracking
